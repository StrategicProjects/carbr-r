# Como citar os dados

A origem dos dados é o Sicar, do Serviço Florestal Brasileiro; a citação
credita a origem e identifica a versão lida.

## Usage

``` r
car_cite()
```

## Value

O texto da citação, invisível; a função o imprime.

## Examples

``` r
if (FALSE) { # interactive()
car_cite()
}
```
